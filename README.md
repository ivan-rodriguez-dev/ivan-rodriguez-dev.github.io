# Portafolio · Iván Rodríguez

Sitio estático (HTML, CSS y JavaScript) listo para GitHub Pages.

## Estructura
```
index.html            Página principal del portafolio
css/styles.css        Estilos
js/main.js            Menú móvil, sección activa y enlace de WhatsApp
img/                  Íconos y mockups de los proyectos (SVG)
demos/panaderia/      Demo de página para panadería
demos/barberia/       Demo de página para barbería
demos/taller/         Demo de página para taller mecánico
```

## Publicar en GitHub Pages
1. En GitHub crea un repositorio llamado **ivan-rodriguez-dev.github.io** (así queda en la dirección principal).
2. Sube todo el contenido de esta carpeta (no la carpeta, su contenido) con "Add file → Upload files".
3. Ve a **Settings → Pages**, en "Branch" elige `main` y carpeta `/ (root)`, y guarda.
4. En 1–2 minutos queda en: **https://ivan-rodriguez-dev.github.io/**

Tus proyectos como Oído en vivo siguen funcionando en sus propias direcciones.
